# Pixel Grammar · Modern Pixel Editorial

Pixel 使用“块状标记 + 有节奏的缺角表面 + 清晰信息排布”共同建立身份。不是游戏 UI、旧系统复刻或给每个卡片套黑框。实现入口为 [style-pack-pixel.css](../../../assets/foundation/style-pack-pixel.css)，通用合约见 [Visual Grammar](../../../foundation/visual-grammar.md)。

## 色板与优先级

默认浅色语法：纸面 `#f0f3eb`、内容 `#fcfdf8`、主文字 `#253b37`、次文字 `#53645d`、主数据深青 `#185c50`、次数据苔绿 `#667b67`、强调赭色 `#96511c`、边界 `#b5c5b5`。选择 Graphite 时用冷纸面变体和更冷的青色；仍是有限 Pixel 色板，保持 Base Theme 可组合。状态色独立于统计好坏，不使用红绿映射显著性。

语法开启时覆盖需要的角色色，关闭后完全继承 Base Theme。显式排印不变；色板优先级不能覆盖对比度、统计编码或用户明确的高对比需求。`--px-*` 是语法角色，不是新增主题。

## 形状、排印与节奏

- 基础单元 4px，缺角/阶梯使用 4/8/12px。只在核心结果和控件边缘使用阶梯，不对所有内容锯齿化。
- 标题使用已选 Typography Profile；局部强调采用块状底线、端点结构和更紧凑的字重关系，不依赖像素字体或全页等宽中文。
- 正文、坐标、表格数字沿用清晰功能字体和 tabular numerals。长中文自动换行，不截断，不因风格放大标题。
- 局部对齐遵循 4px 节奏，保留现有章节间距与主结果面板比例。可选 split Hero 只用于确有双列标题/说明的内容，不强套到报告。

## 组件造型

| 组件 | 语法 |
|---|---|
| Navigation | 开放底部规则线、品牌前小网格标志、方形活动项；避免外层厚框 |
| Hero | 一组低密度像素序列、强调文字下的块状色带；支持居中 editorial 和局部 split |
| Core Result | 轻边界、两处阶梯角、叙述/证据内部规则线，不增加高度 |
| Metric | 字重和等宽数字节奏、短端点强调；不模拟仪表或增加伪指标 |
| Section Heading | 左端小方标、开放分隔；不每节重复 Hero 图案 |
| Chart Container | 内容纸面、四角短定位线；图内网格与数据不作装饰混用 |
| Table | 克制的表头带、细列规则线、清楚行焦点；无整表粗框 |
| Tabs / Buttons | 方形状态块、短下缘反馈、明确选中态与焦点 |
| Accordion | 明确方形加/减号、紧凑规则线，保留原生 details 键盘行为 |

## Chart Grammar

- 数据点采用同中心方形，尺寸固定，与显著性或样本量无关。
- 连续曲线仍连续；真实观测折线保留原始连接方式。禁止用 `steps`、坐标取整或阶梯路径制造像素感。
- 柱形为实心块状，长度和基线不变，不用间断条纹伪装概率或销量。
- CI 保持原范围和可读浅填充；使用清晰边缘。图例采用方形点、连续线段与区间面，语义不混用。
- 多系列用同一有限角色体系与明确图例，不靠像素形状暗示优劣。超出角色数量时由任务适配定义可读编码，语法不自动生成随机色。

## 母题、反馈与降级

母题只用三种：品牌的 3×3 缺格标、Hero 的短像素序列、结果面板的阶梯角。图表里的参考线、点与 CI 不充当装饰。不开随机噪点，不在每章复制整组母题。

交互采用 90ms 的颜色/小幅位移反馈，选中态不只靠颜色。`prefers-reduced-motion` 下关闭过渡与位移。Focus-visible 使用清楚描边，触控/键盘行为不变。

JS 适配缺失或不能识别数据 mark 时保留稳定图形。Style Off 必须移除语法装饰和覆盖点，恢复 Base Theme 的属性及字体。已有独立 Style Controller 仍是状态拥有者，语法适配器只观察状态，不注册另一套主题切换。

## 范围

用于分析叙事、技术演示与作品集报告；密集审计、打印优先或中性视觉要求严格时可关闭。Pixel 是首个完成语法契约的实现，实验台和迁移测试不能证明所有图形/设备兼容或替代用户审美验收。其他三包保持 Experimental。

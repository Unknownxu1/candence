# Change Impact Matrix

建议范围，不是跳过正确性检查的绝对规则。没有有效先前证据时，先建立必要基线；依赖不明按 full。局部修正不运行数据生成器，核验与生成是两件事。

| 改动 / API change | Stage A | Stage B | Stage C |
|---|---|---|---|
| CSS 颜色 / css-color | 可复用指纹一致的通过结果 | 加载、错误和图表冒烟；检查对比度风险 | 相关区域一次截图 |
| CSS 布局 / css-layout | 同上 | 相关组件、可见图表 | 受影响视口与区域 |
| 静态文案 / copy | 数字、口径或解释有变则核验；工具默认保守执行 | 基础检查 | 相关区域与换行 |
| 图表 JS / chart-js | 受影响绑定/数值及坐标 | 相关图表完整检查，在截图前阻断空白 | 相关图表 |
| 指标计算 / calculation | 指标及依赖项复算 | 相应绑定与组件 | 相关结果/图表 |
| 原数据 / raw-data | 所有必要数据核验 | 全部数据相关功能 | 受影响结果与区域 |
| 主题系统 / theme | 通常复用，但编码含义变化则复核 | 受影响切换状态 | 受影响主题/对比度，不默认所有组合 |
| 交互 / interaction | 若改变聚合/数据选择则复核 | 对应交互、状态与错误 | 必要状态 |
| 新报告或未知 / full | 完整必要核验 | 全部必要功能 | 模式内的必要范围 |

仅样式不代表永远不影响数据理解，例如隐藏 CI、改变基线、用面积夸大差异必须重新检查统计表达。图表代码或解释变化不能以 CSS 名称规避 Stage A。数据依赖有变化时，工具会让“仅 CSS”标签的缓存失效。

具体 API、依赖声明和人工复核见 [execution modes](../references/execution-modes.md)。[Completion Gates](completion-gates.md) 达成即停止；按范围复验不等于撤销质量门槛。

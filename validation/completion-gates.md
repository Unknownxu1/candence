# Completion Gates

| Gate | 通过条件 | 不能替代它的证据 |
|---|---|---|
| 1 数据可靠 | 必要来源、口径、计算、对账与结果追溯通过；或复用明确未失效的通过结果 | 只有 JSON 可解析、测试数量或格式检查 |
| 2 报告可用 | HTML/资源加载、真实数据图形与关键交互可用，无阻断 JS 错误 | DOM 容器存在、仅 title/轴可见 |
| 3 视觉合格 | 实际看过本轮所需截图，无明显溢出、空图、严重重叠、不可读关键内容或误导编码 | 自动零报错、截图文件存在、旧页面截图 |
| 4 可交付 | 文件/数据与方法入口/必要说明齐全，未遗漏已知阻断交付问题 | 仍有断链、未提供的数据来源或悄悄跳过的阻断项 |

四项通过后立即停止，交付验证范围与未测范围。不因非关键留白、标题细节或装饰继续迭代。Quick 的证据范围小，不等于将待验项写成通过。浏览器缺失时 Gate 2/3 可能待验，可交付部分成果但不能声称验收完成。

一次初始视觉验收 + 最多两轮集中修正。每轮先记录具体缺陷和复验范围；同一个问题未解不能通过无限截图重试掩盖工具缺陷。预算耗尽仍有阻断项：保留产物、标记 blocked、请用户决定是否追加范围或预算。人工批准扩展时记录原因与新上限。

工具状态：`needs-visual-review` 表示 A/B 与自动布局检查已过但仍待看图；`blocked` 不能交付为已通过；`complete` 且 `stop:true` 才满足四门槛。`completeReview` 检查截图与依赖哈希，但不能证明调用者真实看图。审核人须如实记录观察。跨 Agent 自主停止能力仍需真实运行评估。

# Cadence v0.1.1 · 执行机制验证

本轮是 v0.1.0 的补丁升级：只调整入口、执行规则、测试辅助能力和必要版本元数据；Golden、Design DNA、Composition Patterns、主题、字体、Style Packs、数据和报告运行代码保持不变。

## 运行方案

执行 `npm run test:execution`（现有 Playwright + 可用浏览器）。夹具用当前公开冰激淋输入生成一个临时报告，所有改动发生在 `tests/artifacts/execution/`，不写稳定示例。

| 场景 | 必须观察的行为 | 最终一次夹具调用的实际结果 |
|---|---|---|
| A 局部 CSS 颜色 | A 复用，无数据重生成；B 冒烟；一个区域截图 | 通过；数据验证新增执行 0 次，生成新增执行 0 次，截图 1 张 |
| B 图表 JS 故障 | 可控异常在 B 拦截，不继续 C；修好仅验相关绑定/图表/区域 | 通过；错误版截图 0 张，修复版 1 张；未跑完整多主题回归 |
| C 完整小报告 | 默认 Standard，先 A 再 B 再 C，必要数据核验和关键交互可用 | 生成 1 次；桌面和手机全页各一张；自动结束在待看图状态。随后实际看图、调用签核接口，四门槛通过并停止，视觉修正 0 轮 |
| 停止与预算 | 人工签核前不能 complete；通过后未改内容无需重跑；两轮后阻断；缺陷列表不可空 | 状态机测试以明确标注的模拟签核验证；另在真实看图后验证同一配置再次调用直接返回，不重开浏览器或数据验证 |
| 缓存失效 | 即便标为 CSS，只要源数据变化也不可复用 A | 已注入源数据变化，A 重新检查失败，B/C 未执行 |

机器证据见 [execution-results](../validation/v0.1.1-execution-results.json)，其中分别记录夹具模拟签核与本轮 Agent 真实看图。实际看过的四张截图：[C 桌面](../validation/v0.1.1/C-0.png)、[C 手机](../validation/v0.1.1/C-1.png)、[A 局部](../validation/v0.1.1/A-0.png)、[B 修复](../validation/v0.1.1/B-0.png)。首屏、核心数据、条形/折线、表格与方法入口可见，无明显空图、裁切或严重重叠。未因非关键边距继续改动。

原始执行文件位于忽略目录；测试故障使用临时副本，原示例哈希不变。工具开发中重跑过夹具，表中计数是一轮机制执行内的观察，不是整个工程任务只运行一次测试，也不是运行时性能基准。

- 隐私扫描、静态核验、skill-creator 结构检查通过；SKILL/version/package/lockfile 统一为 0.1.1，安装与相对路径验证通过。
- 原完整浏览器回归通过：三个场景、四种宽度、39 次主题/字体/风格状态变化，数值/几何、CSV、展开、axe、打印、模拟字体降级、单文件和目录迁移均通过，错误和请求失败为零。详见 [regression-results](../validation/v0.1.1-regression-results.json)。

完整回归后，对“截图证据丢失/篡改”和“稳定样式仅插入一次”做了定向保护检查；再次验证当前工具的 C 流程，无数据重生成，新截图哈希与已看过的图片完全相同。当前签核后立即停止检查通过。未为这些局部修补再次执行整个仓库回归。

## 验证边界

- 数据检查回调核对虚构来源、两口径合计、HTML 内嵌数据、显示读数与表格；不是任意分析任务的通用指标审核器。后续任务必须实现自己的计算、口径、追溯和绑定检查。
- “simulated sign-off”只测试门槛与停止机制。实际查看截图后才记录人工观察；未看图时不会给出视觉通过。
- 仅真实 Chrome、模拟视口；不宣称新模型会自主遵守所有规则，也不宣称跨浏览器完成。
- 指纹只能覆盖已声明文件与直接页面脚本；远程 JS、遗漏依赖、动态数据与任务口径改变需保守失效或补充核验。
- 本地 DeepSeek 复盘已读取，但没有复跑两小时 SaaS 报告或同条件计时。预期减少重复生成、无关全回归、故障后截图和无理由修饰；效率收益、时长变化及自主停止表现仍需下一轮 DeepSeek 实测。

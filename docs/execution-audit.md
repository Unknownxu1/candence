# Execution Audit · v0.1.1

范围：SKILL、五层规则、生成/打包/安装脚本、固定案例、静态和浏览器验收、依赖说明。亦实际读取本地测试场的 `evaluation/execution-log.md`、`self-review.md`、`skill-usage.md`、`browser-results.json`、`number-integrity.json` 及 `tools/validate.mjs`；未复制其报告、台账、业务参数或代码到仓库，未重新运行该 SaaS 报告。

记录可核对到 19 个浏览器检查、20 个截图条目及数值追溯结果。这是对现有记录的检查，不是本轮重新认证。没有原始逐工具时间线和可比计时基线，不能独立证明两小时的精确构成或优化百分比。

| 发现 | 证据等级 | 判断与处理 |
|---|---|---|
| Layer 5 要求每份产物覆盖多截图、主题/字体、导出、打印、降级，入口也列广泛检查 | 已有证据：v0.1.0 规范原文 | 对局部改动可能过宽；改为按模式和影响范围调用。原完整仓库回归继续保留 |
| 固定 browser.cjs 在三案例中各跑四宽度、13 个外观状态及多图、axe、PDF | 已有证据：实际脚本 | 它适合维护者全回归，不适合当每份新报告的默认验收；新工具仅验任务相关范围 |
| 原脚本直到最后才统一断言 Console/page errors，截图可先于失败终止 | 已有证据：实际控制流 | B 提前检查错误和真实数据标记，再进入 C；新增注入异常的运行测试 |
| 没有变更影响矩阵、有效结果缓存或修订次数的明确约束 | 已有证据：入口与脚本 | 原有“完成授权范围后停止”过抽象；明确四门槛、一次初验和最多两轮修正 |
| 未区分数据生成与数据验证，局部修复可能触发重新生成/核验全量内容 | 合理推断：规范缺少区分；日志不足以重建每次实际重复 | 工具不调用生成器；以声明依赖与绑定指纹复用通过的 A，而不是跳过核验 |
| 经营台账的对账、识别与口径修正是必要工程成本 | 已有证据：复盘记录了数据口径问题及修正 | 不将这些成本全部归因于 Skill；A 正确性要求不降低，不缓存错误结论 |
| 图表接口引用、编码和截图状态属于工具/实现故障 | 部分已有证据：本地验证器含硬编码浏览器路径、固定等待、裁剪逻辑；复盘描述接口适配问题。具体编码损坏过程尚待验证 | 抽取原有可用的字体/帧等待思路，独立实现有界 helper；不复制业务验收代码，也不宣称所有事故已复现 |
| 图表 x 轴数值与标签语义、字体覆盖、风格适配仍有限 | 已有证据：本地 skill-usage 与当前 helper 代码 | 本轮仅说明数值坐标契约和降级，未扩展图表、字体或风格能力 |
| 首屏多轮微调可能缺少足够明确的缺陷与终止标准 | 合理推断：复盘包含适配记录，但缺少完整逐次编辑时间线 | 合格后停止，不以微小留白为迭代理由；是否减少实际模型反复，尚待下一轮实测 |

按需项：未启用主题/风格、打印、额外设备、字体降级、完整 axe、独立模型行为评估。触及相应系统或用户要求时仍应做；“按需”不意味着丢弃必要数据和功能检查。

可复用项：B 的资源/错误/数据标记冒烟、明确 popover 状态、滚动/截图稳定、A 的证据指纹、阶段顺序/跳过记录、修订计数与完工停止。任务特定计算、数据口径、结论解释和人工看图仍由执行 Agent 负责，工具不替代它们。

对应实现与限制见 [执行模式](../references/execution-modes.md)，结果见 [v0.1.1 validation](v0.1.1-validation.md)。**尚待验证**：同条件 DeepSeek 执行时长、实际工具调用次数、Agent 是否正确声明依赖并遵守修订预算；当前没有百分比效率结论。

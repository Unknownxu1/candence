# Layer 5 · Visual Validation

默认 Standard，Quick / Deep 范围见 [执行模式](execution-modes.md)。按 A→B→C 完成必要质量检查，按 [影响矩阵](../validation/change-impact-matrix.md) 选择重跑范围。没有实际截图和看图不能声称视觉验收完成；自动检查、Agent 看图、用户认可分别记录。

## A · Data Integrity

核对来源、数据性质、计算公式、口径/单位/基准、结果与原数据追溯、统计限制及需要的对账关系。已有报告按变更的指标与依赖项核验，不重新生成数据来验证 CSS。保存核验结果及依赖指纹；仅数据/计算/绑定/相关输出有变化或证据失效时重跑受影响检查，首次或范围不明保守执行。

## B · Functional Validation

截图前真实加载 HTML，检查资源、Console/page errors、核心图表的数据 mark 与有限几何、读数与数据绑定、必要控件。容器/轴存在不等于图表正常。任何阻断失败先修复，禁止继续整批截图。修复图表 JS 后检查其数据绑定、图形及相关交互，避免复跑无关生成流程。

## C · Visual Validation

Standard 检查桌面和窄屏的首屏构图、核心面板、关键图表、主要表格、溢出与可读性；局部改动截相关区域与受影响视口。Quick 不默认全页、多视口或多主题回归。未启用的主题/表达包不默认测试；仅主题系统改动、Deep 的明确范围或用户要求时扩展。字体降级、导出、打印、额外设备根据依赖或任务需要执行。

截图前等待必要 ready 状态、字体与图表稳定，停用/等待平滑滚动，明确 popover 打开/关闭状态。优先元素截图而非自算越界 clip。辅助工具的等待有上限，不以无限重试隐藏错误。实际看图检查重心、结构平衡、重叠、空图、裁切、关键内容与统计编码；零自动违规不能代替观察。

一次初始验收后最多两轮集中视觉修正；每轮列具体缺陷、影响范围及复验项。不为“还可以更精致”继续改。四项 [Completion Gates](../validation/completion-gates.md) 全通过即停止；预算用尽仍有阻断，标记 blocked 并请求用户决定。

## 可复用工具与仓库回归的边界

[执行模式](execution-modes.md) 给出 [browser-review.cjs](../scripts/browser-review.cjs) 和 [review-report.cjs](../scripts/review-report.cjs) 的接口、依赖声明、缓存及限制。工具核对文件/截图指纹，不能替代任务特定的数据核验或真实人工看图。

`npm run test:execution` 是执行机制的小型真实浏览器夹具。`npm test` / `npm run test:browser` 保留为 Cadence 维护者的完整仓库回归，覆盖三个案例、四主题、多视口、实验风格、导出、打印和模拟字体降级；不是每生成一份报告都要执行的工作流。它们生成 `tests/artifacts/` 的真实证据，不覆盖稳定示例或已归档截图。

浏览器不可用：交付静态核验与待验项，不标记 Gate 2/3 已通过；字体缺字采用已声明降级链并在相应视口复查；风格干扰阅读先关闭表达层。工具故障和内容缺陷分别记录，修复一次后只重跑必要阶段。

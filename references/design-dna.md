# Layer 1 · Design DNA

本层规定通用视觉关系与默认尺度，配套示例采用虚构冰激淋场景。

| 不变量 | 推荐起点 | 内容适配 |
|---|---|---|
| 单一主阅读轴，文字和证据共享边缘 | 原案例 1080px，导航稍宽 | 宽表局部横滚；不自动变成侧栏仪表盘 |
| 标题、问题、整体结果面板互相支撑 | 原 Golden 居中 Hero，核心面板约 43:57；后续同家族 | 标题自然换行；不把字号放大到挤压 CI 或语境 |
| 字号有职责，中文不套英文负字距 | 正文 16px、注释 12–14px、核心数与标题相近量级 | 手机按角色调整，不整页缩放；长标题不能裁切 |
| 组间距离大于组内，章节密度有差别 | 章节间约 96–104px，局部 24–48px | 留白服务关系，不要求每节相同高度 |
| 低色度纸面与开放排版 | 浅灰/白建立段落，小面积重点色 | 风格可有受限材质变化，不吞没内容 |
| 一张画布承担一个比较任务 | 主结果面板、主证据图各整合成单元 | 不把 KPI、段落、方法都装盒子 |
| 不确定性与数据支持是证据的一部分 | 数值、点、区间和标签相互对应 | 多行增加行高；窄屏重排，不隐藏区间 |
| 同一套尺度允许多种局部构图 | 首屏整合、发现开放、证据完整、方法紧凑 | 不机械逐节换花样，也不全页等密度 |

基础主题控制角色颜色；排印和实验性表达层可有边界地改变字形、笔触与材质。某次实验的局部限制不应成为所有报告的固定模板。

最终审查整体比例与阅读顺序，不逐像素复制案例。[Golden 示例](../examples/golden-first.html) 是虚构冰激淋销量报告，用于展示构图，不是通用分析引擎。

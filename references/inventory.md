# 公开资源与成熟度

本清单说明设计规则、视觉资源与虚构冰激淋示例的用途和验证范围；实现、浏览器测试与用户认可分别记录。

| 资源 | 来源与边界 |
|---|---|
| Design DNA / Composition Patterns | 通用秩序、比例和构图关系 |
| Base Themes / Typography | 四主题、四字体配置；OFL 字体及其原许可独立保留 |
| Expressive Style Packs | 四包仍为实验性；实际测试以 validation 为准 |
| Golden 示例 | 基于虚构销量输入生成的单文件 |
| 因果展示 | 虚构试吃方案；效应和区间手工构造，仅测试展示，不是真实估计 |
| 排序展示 | 1,600 名虚构试吃参与者、四种口味；种子 7319、实际重新拟合，无外部输入 |
| 销量展示 | 虚构口味计数和四周总量；不代表真实经营数据 |
| 截图与测试 | 虚构案例的实际浏览器产物，测试范围见验证记录 |

当前产物哈希见 [source-manifest.json](source-manifest.json)。示例数据约定见 [Example Data](../docs/example-data-policy.md)，许可与第三方声明见 [licensing review](../docs/licensing-review.md)。

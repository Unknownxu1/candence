# Layer 4 · Content & Data Presentation

本层规定内容选择、表达方式和披露顺序。与 Design DNA、Composition Patterns、Hallmark Theme System 及 Visual Validation 配合使用；它不是新的页面模板，也不是已发布的 Skill。研究任务和统计语义优先于固定字数、组件数量和视觉整齐。

## 1. Information Selection：先判断价值，再决定位置

开始排版前，写下读者、研究问题、估计对象、主要比较、证据和可能改变判断的限制。对每条信息依次回答：

1. 它使读者理解哪个对象、比较或决定？无法回答时，考虑删除。
2. 如果省略，读者会产生什么具体误解？会改变方向、大小、适用范围或证据强度时，提高优先级。
3. 图形、表头或相邻文字是否已经表达？若重复，记录重复展示的独立阅读价值。
4. 读者在什么位置需要它？把说明放在依赖它的结论、图或表旁，而不是统一堆到首屏。
5. 它应默认可见、就地解释、按需展开，还是删除？不要以“内容正确”作为默认展示的充分理由。

| 层级 | 判断标准 | 默认处理 | 不能机械分类的例子 |
|---|---|---|---|
| P0 核心 | 缺失会直接改变主要结论的理解 | 直接展示；必要时与核心结果绑定 | 模拟性质、核心对比及 CI、无法支持尾段方向的证据 |
| P1 上下文 | 在当前比较中消除歧义 | 紧邻对应内容 | 单位、比较基准、标准化对象、图边支持范围 |
| P2 技术 | 复核必需，但当前理解不必逐项阅读 | 有明确名称的详情、技术表、附录 | 优化器、公式、参数协方差、种子与复现路径 |
| P3 冗余 | 删除后不损失理解、操作或追溯能力 | 删除 | 未被引用的编号、无用途的日期、重复导语、自证式说明 |

同一信息可在不同位置有不同等级。小样本导致不稳定时，样本量可能是 P0；复杂抽样的有效样本量不能被原始总人数替代。窗口截断、随访不足或外推风险决定结论时，时间范围必须在结果附近出现。不能把所有限制塞入 P2，也不能把所有技术词都判为 P3。

新增默认文案需填写一句“存在理由”；隐藏或删除则填写“省略风险及替代位置”。风险无法消除时，保留默认展示。

## 2. Presentation Selection：按阅读任务选表达

| 读者任务 | 首选表达 | 必备语义 | 避免 |
|---|---|---|---|
| 记住一个主要差异 | 指标与必要比较证据组成一个整体面板 | 对象、单位、基准、区间、数据性质 | 无对象大数字、把多个无关 KPI 塞成主视觉 |
| 比较类别的估计及不确定性 | 点区间图；简单数量可用条形图 | 共同尺度、参考项、估计类型 | 仅用排序宣称最优、用颜色暗示显著 |
| 理解连续变量的形状 | 曲线与必要置信带 | 横纵轴定义、支持范围、区间类型 | 根据算法名称自动画曲线、以截轴夸大差异 |
| 查找或核对精确数值 | 表格 | 单位、清晰表头、行标识、同口径比较 | 用冗长文字逐行复述表格 |
| 理解离散预测分布 | 概率条或小表 | 概率总和、类别定义、与均值的区别 | 把均值置信区间当个体预测区间 |
| 理解条件、限制和推断 | 短段落或少量有层次条目 | 具体影响及适用对象 | 为一句边界另造图表、套话式免责声明 |
| 检查模型或参数 | 紧凑表格及命名明确的详情 | 指标方向、可比性、参数尺度 | 从漂亮曲线直接宣称模型优胜 |
| 探索月份、模型、分组 | 小型交互控件 | 当前状态、联动范围、可访问读数 | 让核心结论依赖用户猜测操作 |
| 复现研究 | 技术详情、文件链接与下载 | 数据版本/种子、步骤、依赖、结果来源 | 将复现路径堆在 Hero |

已有图表能完成任务时，优先删重复文字。只有明确提高理解效率且不引入更高阅读成本时，才把文字换为新表达。指标数量、图表数量和详情数量均不设必须填满的配额。

## 3. Editorial Restraint：逐项控制注意力成本

### 标题与导语

- 标题命名内容或表达有证据支持的主要发现。避免刻意对仗、口号、无信息的双行断句。
- 不强制每节都有眉题、标题、副标题和导语。若导语只重述标题或预告下一组件，删除。
- 已认可的标题可保留；不能为减少文字而重造整个叙事或改变视觉层级。
- 英文保留有检索、专业术语或操作价值的部分；重复翻译和内部版本标签不应默认占位。

### 元信息

- 日期仅在时效性、数据截点、引用或版本追溯需要时出现。复现种子即使长得像日期也不是装饰信息。
- 算法名称、样本量和窗口各自判断价值，不能作为标准 Hero 套餐。
- 模拟、合成、实测、预测必须明确。删除重复声明时，检查首屏、导出和脱离上下文传播的图表是否仍能辨认数据性质。
- 装饰编号若没有导航、交叉引用或步骤意义则删除。

### 图注与重复

- 图注只解释未被图形和标注充分表达的尺度、比较、区间、条件或操作。
- 不在图后逐项朗读图中的高低、斜率和已标数值。
- 同一结果出现在摘要与完整表中通常有价值；出现在标题、导语、图题、图注和相邻正文五次通常没有。
- 重复允许有独立目的：首屏快速理解、图表独立阅读、专业读者核对。为每处重复指定目的。
- 不为留白补内容，也不因删文案而增大标题、间距、面板最小高度或装饰。

### 语言

使用具体对象和动词。删去“值得注意的是”“不难发现”等空引导语，以及“不是手工编造”“系统完美呈现”等自证式文案。结论强度服从证据：差异未检验，不能写成“显著优胜”；方向不确定，不能用点估计宣布逆转。

## 4. Progressive Disclosure：理解、核验、复现

| 阅读层次 | 默认可见 | 按需入口 |
|---|---|---|
| 核心理解 | 问题、主要发现、必要区间、关键限制、模拟性质 | 不把核心答案藏入交互 |
| 主要证据 | 主图、比较表、单位与基准、支持范围、当前状态 | 替代模型叠加、精确读数 |
| 方法摘要 | 分析单位、估计对象、主模型/验证口径、适用条件 | 明确命名的研究设定、识别假设 |
| 统计复核 | 关键估计表、影响判断的边界 | 公式、协方差算法、完整参数与细表 |
| 复现 | 清晰入口 | 数据、脚本、种子、依赖、验证划分、导出与完整结果 |

详情标题要能让专业读者知道哪里有答案，避免笼统“更多信息”。按主题组织，不为隐藏每句话增加一行开关。详情仍属于正文，展开后应完整、清楚、可复制，打印时全部展开。

主分析固定而交互图可切换时，两者身份必须清楚。设计设置不应重置分析状态；导出应标识当前模型和数据性质。折叠不应破坏键盘顺序、辅助技术读取或打印恢复状态。

## 5. Statistical Integrity：不能为了简洁牺牲的语义

| 必须可明确找到的信息 | 默认展示条件 | 可进入详情的部分 |
|---|---|---|
| 估计量、方向与单位 | 核心数值与坐标旁必须无歧义 | 完整公式及等价算法 |
| 比较基准与总体 | 变化量旁；总体差异会改变理解时 | 详细纳入排除及标准化权重 |
| 不确定性 | 与主要估计同时展示；非显著或不稳定结论不得掩盖 | 协方差计算、推导、数值细节 |
| 区间类型 | 均值/个体、逐点/同时等易混淆处就地说明 | 离散覆盖算法、参数不确定性是否混合 |
| 数据支持与样本 | 外推、小样本、尾段稀疏、有效样本不足时默认保留 | 不改变判断的完整样本台账 |
| 识别与因果边界 | 可能误解为因果的核心结果附近 | 完整识别条件、潜在失效情形 |
| 模型/验证口径 | 比较模型时必须同口径并说明损失方向 | 公式、划分细节、优化器和收敛诊断 |
| 多重性与探索性 | 会改变结论强度的探索结果旁 | 完整检验家族、校正算法 |
| 缺失、重复测量、候选集变化 | 已影响本次结果时不能仅藏方法 | 未发生但迁移应用需检查的适用条件 |
| 模拟机制与现实外推 | 模拟标识首屏可见；结论不能宣称业务有效 | 完整生成参数与种子 |

不能用两组边际 CI 的重叠代替差异检验；联合差值区间必须来自相应联合推断。不能把排名百分位当购买概率、个体确定名次或客户群体分位数。不能把横截面的月份关联写成同一个人随时间衰减。不得修改数值、轴域、统计对象或选择性删去反例来提高版面简洁度。

## 6. 实施与验收

1. 冻结来源与数据，建立默认及展开状态的全页文案清单；覆盖动态状态、图内文字、表头、帮助和导出反馈。
2. 按 P0–P3 审计，记录原信息、处理、理由、替代位置和统计影响；对可能影响解释的编辑加“⚑”。
3. 在新版本编辑，保持已认可的布局、字体、主题和图表；文字减少自然回流即可。
4. 比较同浏览器、同视口、同主题/字体、同模型/月份、同折叠状态的原版与新版首屏、全页和方法区。
5. 逐项核对：注意力是否集中、结论能否更快理解、限制是否可见、技术细节是否能找回、是否出现空洞、窄屏是否溢出。
6. 验证数据同源、图表尺度、交互联动、导出、打印和主题字体独立性；区分自动检查、实际截图观察和用户审美认可。

不以删字比例作为通过阈值。成功是默认阅读足以正确理解，展开阅读足以核验，复现入口足以找到依据。完成本轮即停止，等待用户验收。

应用限制

固定四候选项、完整排序、无并列、独立试吃参与者及 IIA 是本例设定。真实研究若有候选集变化、重复测量、并列或选择性缺失，需要调整模型与方差估计。间隔天数变化与试吃参与者构成变化可能混杂；观察关联不自动代表口味记忆变化或门店经营效果。有限样本和模型设定也会影响区间覆盖率。

模型定义与间隔天数效应的识别

Rank-ordered Logit 将一次完整排序写为对剩余候选集合的顺序选择。本例与无并列的 Plackett–Luce 模型对应，采用最大似然估计，不是对四个名次分别拟合独立二元模型。

P(r | X) = ∏ₛ exp(Vᵣₛ) / Σⱼ∈remaining(s) exp(Vⱼ)

香草口味效用为 α + f(间隔天数) + β × 偏甜口味状态；巧克力冰激淋和草莓冰激淋各有一个常数，抹茶冰激淋常数固定为 0。间隔天数和偏甜口味状态仅作用于香草口味；若把共同间隔天数项同等加入所有候选，它会在概率中抵消，无法识别。

自然样条：边界 0/24 天，内节点 6/12/18 天，间隔天数基函数 4 个自由参数。线性：间隔天数/12。连续分段：间隔天数/12 与 max(间隔天数−9, 0)/12。节点在模拟拟合前固定，不根据展示曲线挑选。

排名百分位、置信区间与预测区间
排名百分位 = 100 × (4 − rank) / 3

预测均值可由完整排序分布求期望，也可用 PL 的成对先后概率求和得到，两种算法在本次计算中核对一致。均值按固定偏甜口味参与者比例标准化；50% 不对应某个必须穿过的间隔天数。

参数协方差取观测信息矩阵的逆。均值 CI 用 Delta 法与正态近似；间隔天数差值使用两时点梯度之差和完整联合协方差。主分析置信区间是逐点区间。尾段对比为探索，不用于另外宣称经过校正的多重发现。

个体预测分布通过枚举四项的 24 种完整排序得到；等尾 95% 预测区间在离散尺度上实际覆盖率可以超过 95%。此处参数估计视为给定，未把参数不确定性额外混入个体分布。

模拟、拟合与五折验证的复现口径

随机种子 7319。先模拟 0–24 天与二元偏甜口味状态，再按候选效用加独立标准 Gumbel 误差生成完整排序。数据生成机制本身含有非线性，因此验证结果只说明系统能否正确呈现该模拟场景，不能作为真实业务证据。

Python 使用 NumPy 与 SciPy，解析似然梯度、观测信息矩阵、BFGS 优化。所有模型的最大绝对得分小于 10⁻⁴，信息矩阵为正定。五折对试吃参与者划分并复用同一划分，表内 NLL 为五折均值；折间波动不被解释成独立样本的置信区间。

文件夹内提供模拟试吃参与者 CSV、完整拟合 JSON 与复现脚本 data/simulate_and_fit.py。HTML 使用同一 JSON 的内嵌副本，打开页面时不需要 Python 或联网。

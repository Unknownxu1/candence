# Changelog

## 0.2.0 — 2026-10-16

- 在 Layer 3 中新增 Visual Grammar 合约，覆盖形状、排印表达、表面、组件、数据标记、装饰、反馈与局部节奏，保留五层架构。
- Pixel v2 采用有限色板、阶梯表面、开放导航、标题局部结构、表头/控件状态和方形标记；不改变曲线、区间、坐标或分析含义。
- 新增可选的通用图形适配器与无文件输出的合约测试；支持可逆切换、点命中区、位置更新和缺失适配时的稳定降级。
- 生成器携带语法适配器，风格关闭时不改变图形；旧报告、Golden、基础主题及字体配置保持兼容。其他三种表达包继续 Experimental。
- 增加独立实验工作区规则与 CADENCE_TEST_OUTPUT 输出配置，实验数据、报告、截图和一次性验收记录由使用方工作区管理。

## 0.1.1 — 2026-10-16

- 新增 Quick / Standard（默认）/ Deep 执行模式、A/B/C 分层验证、变更影响矩阵与四项 Completion Gates。
- 限定一次初验及最多两轮集中视觉修正；通过后停止，阻断项或未看图不能标记完成。
- 新增轻量浏览器辅助与可选执行工具，按依赖指纹复用数据验证；提前拦截图表/JS 故障，记录实际执行和跳过范围。
- 使用公开虚构夹具验证局部 CSS、图表故障及完整小报告；保留原有完整仓库回归，不更改视觉资产或统计逻辑。未宣称同条件执行时间改善。

## 0.1.0 — 2026-10-16

- Added fictional ice-cream examples, reproducible synthetic ranking data, browser screenshots and public-example checks.
- Added the draft Cadence Source-Available License 1.0 (Free to use. Not for resale.), README licensing guidance, third-party review, and custom-license metadata; copyright holder confirmation and legal review remain pending.
- Renamed the project and Skill to Cadence (`cadence`); retained Hallmark Theme System module identifiers and existing report designs.

- Extracted the verified editorial report foundation into a five-layer Agent Skill with progressive reference loading.
- Preserved four base themes, four typography profiles, OFL font subsets and public synthetic examples.
- Included four expressive style packs as experimental; kept Rank-specific adapters separate.
- Added a small independent design-state controller, native SVG helpers and optional JSON report starter for interval, bar and short trend displays.
- Added explicit-target installation and local CSS/JS single-file packaging utilities.
- Added three fixture scenarios, portable static/browser validation and release audit; actual results and limitations are recorded separately in validation artifacts.
- No remote repository or package publication was performed during initial packaging. The proposed custom redistribution license remains pending owner confirmation and legal review.
